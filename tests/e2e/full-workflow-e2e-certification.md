# C17 Full Workflow E2E Certification Scenario Map

This folder records the runtime test plan for Pass C17. The executable runner is `scripts/full-workflow-e2e-certify.mjs` and the Vitest acceptance map is `backend/src/modules/e2e-certification/full-workflow-e2e.integration.test.ts`.
