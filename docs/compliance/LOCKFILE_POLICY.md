# Lockfile Policy

NEXORA uses exactly one workspace lockfile at repository root:

```text
pnpm-lock.yaml
```

Allowed package manager:

```text
pnpm@10.15.0
```

Forbidden lockfiles:

```text
package-lock.json
npm-shrinkwrap.json
yarn.lock
bun.lockb
```

The lockfile must be generated by pnpm from the registry. It must not be fabricated, hand-written or copied from another project.

PASS M1 adds `scripts/check-lockfile-policy.mjs` and `scripts/pass-m1-dependency-lockfile-certify.*` so the lockfile can be generated and verified on a connected machine.
